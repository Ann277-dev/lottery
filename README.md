# 🎉 同学抽奖机

一个趣味聊天式抽奖网页，扫码就能打开，和同学一起玩！

## 🎁 奖品

| 奖品 | 概率 |
|------|------|
| 🔫 中大水枪玩具 | 10% |
| 🔫 中小水枪玩具 | 15% |
| 🥤 可乐一听 | 20% |
| 🧸 中捏捏乐 | 25% |
| 😅 谢谢参与 | 30% |

每天 3 次抽奖机会，凌晨刷新。

## 🚀 快速启动

### 方式一：直接打开（最简单）

直接用浏览器打开 `index.html` 即可。

### 方式二：本地服务器 + 公网链接（扫码用）

```bash
# 1. 启动本地服务器
npx serve .

# 2. 另开终端，用 Cloudflare Tunnel 生成公网链接
npx cloudflared tunnel --url http://localhost:3000

# 3. 把生成的 https://xxx.trycloudflare.com 链接生成二维码发给同学
```

### 方式三：部署到 GitHub Pages

1. 把这个文件夹 push 到 GitHub 仓库
2. 在 Settings → Pages 中启用 GitHub Pages
3. 把链接生成二维码

## 📱 生成二维码

页面底部有「扫码分享给同学」链接，点击即可生成当前页面二维码。

也可以把部署后的链接粘贴到任何二维码生成工具中。

## 🛠 技术栈

- 纯 HTML/CSS/JS，单文件，零依赖
- 移动优先响应式设计
- localStorage 存储抽奖记录和次数限制
